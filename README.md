# 사막여우계단

안개 낀 밤, 교복을 입은 아바타로 스물여덟 개의 돌계단을 오르는 3D 메타 공간입니다.
계단 중간중간 튀어나오는 손을 뿌리치고 꼭대기에서 "사막여우야 사막여우야 내 소원을 들어줘"를 외치면,
소원을 종이에 적어 고목 가지에 매달 수 있어요. 같은 시간에 접속한 사람들은 서로의 아바타를 보고
손 흔들기, 목 돌리기, 계단에 앉기로 인사할 수 있습니다.

## 조작

| 동작 | PC | 모바일 |
| --- | --- | --- |
| 이동 | 방향키 / WASD | 왼쪽 아래 조이스틱 |
| 발목 잡혔을 때 빠져나오기 | 클릭 연타 또는 스페이스 | 화면 연타 |
| 소원 빌기 (계단 끝) | 버튼 또는 E | 버튼 |
| 손 흔들기 · 목 돌리기 · 앉기 | 오른쪽 아래 아이콘 | 오른쪽 아래 아이콘 |
| 걸린 소원 읽기 | 종이 클릭 / 오른쪽 위 목록 | 종이 터치 / 오른쪽 위 목록 |

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 페이지 뼈대 |
| `style.css` | 화면 디자인 |
| `main.js` | 3D 장면, 아바타, 귀신 손, 소원, 배경음악, 멀티플레이 |
| `config.js` | Supabase 연결 정보 (직접 채워 넣기) |
| `supabase.sql` | 소원 저장 테이블과 보안 규칙 |

빌드 과정이 없는 정적 파일이라 GitHub Pages에 그대로 올리면 됩니다.

## 1. GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다 (`index.html`이 저장소 맨 위에 있어야 해요).
2. 저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 `main` / `/ (root)`로 정하고 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 열립니다.

여기까지만 하면 **혼자 체험하는 모드**로 동작합니다. 소원은 각자의 브라우저에만 남고 다른 사람은 보이지 않아요.

## 2. 여럿이 함께하기 (Supabase 연결, 무료)

소원 공유와 실시간 아바타는 [Supabase](https://supabase.com) 무료 프로젝트 하나로 동작합니다.

1. supabase.com에 가입하고 **New project**를 만듭니다 (지역은 Northeast Asia (Seoul) 추천).
2. 왼쪽 메뉴 **SQL Editor**에서 `supabase.sql` 내용을 통째로 붙여넣고 **Run**을 누릅니다.
3. **Project Settings → API**(또는 **Connect**)에서 **Project URL**과 **anon public** 키를 복사합니다.
4. `config.js`의 `supabaseUrl`, `supabaseAnonKey`에 붙여넣고 GitHub에 다시 올립니다.

이제 같은 주소로 들어온 사람들끼리 서로의 아바타가 보이고, 누군가 소원을 매달면 모두의 고목에 바로 나타나요.
오른쪽 위 사람 아이콘 옆 숫자가 지금 함께 있는 인원입니다.

### 알아두면 좋은 점

- **anon 키는 공개해도 되는 키**입니다. 보안 규칙이 "읽기"와 "새 소원 쓰기"만 허용해서, 남의 소원을 고치거나 지울 수 없어요. `service_role` 키는 절대 올리지 마세요.
- **소원 지우기**: 장난스러운 소원은 Supabase 대시보드 **Table Editor → wishes**에서 행을 지우면 열려 있는 화면에서도 바로 사라집니다.
- **소원은 49일 동안 걸려 있어요.** 마지막 사흘은 종이 가장자리가 그을리고, 49일이 지나면 불씨가 되어 타올라 사라집니다. 탄 소원은 화면에 다시 나오지 않아요 (데이터베이스에는 남아 있고, `supabase.sql` 맨 아래 문장으로 정리할 수 있어요).
- **고목이 가득 차면** 주변의 죽은 나무들에 종이가 걸리기 시작하고, 그 나무에도 금줄이 둘러집니다. 꼭대기 고목 → 꼭대기 숲 → 계단 옆 나무 순서로, 모두 합쳐 1,300장 넘게 걸 수 있어요.
- `supabase.sql`을 예전에 실행했다면 새 버전을 한 번 더 실행하세요. 다섯 개 제한이 "지금 걸려 있는 소원" 기준으로 바뀝니다.
- **다섯 개 제한**은 지금 걸려 있는 소원 기준이고, 브라우저마다 적용됩니다. 로그인이 없는 구조라 시크릿 창으로 우회할 수는 있어요.
- 무료 플랜은 일주일 넘게 아무도 쓰지 않으면 프로젝트가 일시정지될 수 있어요. 대시보드에서 다시 켜면 됩니다.

## 내 컴퓨터에서 미리 보기

`index.html`을 더블클릭해도 열리지만, 로컬 서버로 여는 것이 가장 정확합니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

## 사용한 것

- [three.js r128](https://threejs.org) (3D 렌더링, CDN)
- [supabase-js 2](https://supabase.com/docs/reference/javascript) (소원 저장 · 실시간 접속, CDN)
- Google Fonts: Song Myung, Gowun Dodum
- 배경음악과 효과음은 Web Audio로 브라우저에서 직접 합성합니다 (외부 음원 없음).
